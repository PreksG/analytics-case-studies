# Analytics Case Studies

Case studies from my work as a Data Analytics Engineer with a background in FP&A and financial reporting. Each one follows the same story: **business problem → data → method → validation → business value**.

All case studies are anonymised. Company names, internal systems, real figures and proprietary rules are not published. Any demonstration data is synthetic.

## How to read the status labels

- **Implemented** — built and used.
- **Partially implemented** — some components complete; scope remains.
- **Recurring responsibility** — ongoing reporting work rather than a one-off build.

Each case study separates what I did from what others did, and marks anything not yet measured as *Not yet quantified*.
